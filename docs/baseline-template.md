# Phase 0 baseline

No code runs in this phase. Write your next three real problems in the post
template, run each through the built-in Research feature in the Claude app by
hand, and measure the error rate before deciding the think tank is worth it.

Kill criterion (design section 11): if Phase 1 does not beat this baseline on
claim accuracy after 6 problems, stop and keep using the built-in feature.

## Problem post template

Copy one block per problem. The same fields are what the inbox board asks for.

```
Mode:               research | ideas
Question:           One sentence.
Decision it feeds:  What you will do with the answer.
Must-answer list:
  1.
  2.
  3.
Evidence standard:  Source type and maximum age (e.g. primary sources, no older than 12 months).
Deliverable:        Format and length (e.g. 2-page brief plus a comparison table).
Token cap:          e.g. 3000000
Deadline:           e.g. 07:00 (next occurrence) or 2026-09-20T07:00
```
